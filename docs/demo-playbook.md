# 多模态 RAG 与 Agent：5 分钟演示脚本

## 演示前

在 Windows PowerShell 保持 SSH 隧道：`ssh -N -L 8010:127.0.0.1:8010 my-ai-server`，浏览器打开 `http://127.0.0.1:8010/`。

## 1. 文本知识问答（约 1 分钟）

提问：`员工每周最多可以申请几天远程办公？`

说明：系统使用 BGE-M3 将问题向量化，在 FAISS 中检索企业制度，再由 Qwen 仅依据引用内容回答。展示答案中的“两天”和来源引用。

## 2. 拒答能力（约 30 秒）

提问：`员工年假一共有几天？`

说明：知识库没有年假制度，系统返回无法确定，不把低相关资料伪装为证据。

## 3. DINOv3 跨视角检索（约 1 分钟）

在“视觉相似检索”上传无人机查询图，点击“查找相似图片”。

说明：图库含 701 张 University 卫星参考图；DINOv3 将查询图编码为 1024 维向量并在图像 FAISS 中检索。展示 Top-1 卫星图、地点编号和相似度。

## 4. 多模态理解（约 1 分钟）

输入问题：`这张图片中能看到什么？`，点击“理解图片并检索”。

说明：同一图片被送入 Qwen-VL 获取可见内容描述，并送入 DINOv3 检索视觉相似参考图。

## 5. Agent 工具调用（约 1 分钟）

在“Agent 工具调用”输入：`查询服务器 GPU 当前状态`。

说明：LangGraph 路由 Agent 识别为运维问题，调用 `nvidia-smi` 工具，而不是进行知识库问答。再输入远程办公问题，展示它改走知识库工具。

## 收尾说法

这个项目把我已有的 DINOv3 跨视角视觉检索能力，与 BGE-M3、FAISS、Qwen-VL 和 LangGraph Agent 连接成了一套可部署的多模态 AI 应用；下一步可进一步加入 Docker、Milvus、权限和异步任务队列。
