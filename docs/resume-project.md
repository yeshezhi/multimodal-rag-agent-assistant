# 简历项目描述：企业知识库 RAG 智能问答系统

**项目定位：** 基于本地大模型的企业知识检索增强生成系统，支持内部制度、运维手册和项目交付资料的上传、语义检索、可信问答与来源追溯。

**技术栈：** Python、FastAPI、BGE-M3、FAISS、Qwen3-VL-4B-Instruct、LangChain、Transformers、PyTorch。

**个人工作：**

- 设计并实现“文档解析 → 中文文本切分 → BGE-M3 向量化 → FAISS Top-K 检索 → Qwen 生成 → 引用返回”的端到端 RAG 链路，支持 PDF、DOCX、Markdown 和 TXT。
- 实现知识库上传、状态查询、单文档删除、索引持久化和网页交互接口；服务运行在 RTX 4090 环境，并通过 SSH 隧道安全访问。
- 增加相似度阈值拒答机制，避免模型在检索依据不足时编造答案；回答同步输出来源片段和相似度，支持人工追溯。
- 构建 18 道题的检索评估集，使用预期来源命中率衡量 Recall@K；基础三文档基线测试取得 `Recall@3 = 100%`。

**可写在简历的一句话：**

基于 BGE-M3、FAISS 与 Qwen 构建企业知识库 RAG 智能问答系统，实现多格式文档解析、1024 维语义检索、引用溯源与低置信度拒答；设计检索评估集并完成端到端部署验证。
